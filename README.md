# مدرّب الستيب (step-coach)

تطبيق ويب يدرّسك للستيب يوم بيوم: درس تفاعلي، تمرين، واختبار على الدرس ثاني يوم، ومراجعة متباعدة لغلطاتك، ونقاط وأوسمة، ودرجة متوقعة تتحدث مع تقدمك.

## الملفات
- `src/worker.js` الـ API: يكلم Claude ويحفظ في D1
- `src/curriculum.js` منهج ١٨ أسبوع (٩٠ يوم دراسة، من الأحد للخميس)
- `src/podcast.js` حلقة المشي اليومية (بودكاست خاص)
- `tools/podcast/render.py` و `.github/workflows/podcast.yml` تسجيل صوت الحلقة في GitHub Actions
- `public/index.html` واجهة التطبيق
- `schema.sql` جداول قاعدة البيانات (منفّذة مسبقاً على step-db)
- `wrangler.toml` الإعدادات

## خطوات النشر
1. أنشئ مستودع جديد في GitHub باسم `step-coach` وارفع كل الملفات بنفس الترتيب.
2. Cloudflare ← Workers & Pages ← Create ← Import a repository ← اختر `step-coach` ← Deploy.
3. بعد النشر: Settings ← Variables and Secrets، وأضف:
   - `ANTHROPIC_API_KEY` نوع Secret: مفتاحك من console.anthropic.com
   - `APP_KEY` نوع Secret: كلمة مرور تختارها لدخول التطبيق
4. افتح رابط الـ Worker، واكتب كلمة المرور، وابدأ.

## النماذج والتكلفة
- `MODEL` (Sonnet 5.5): الدروس، وجزء القواعد والأسئلة في الحلقة.
- `POD_LISTEN_MODEL` (Haiku 5.5): جزء الاستماع في الحلقة.
- `DAILY_CAP_USD`: حد الصرف اليومي (افتراضي ١$). لو وصله التطبيق يوقف طلبات Claude لين بكرة.
- صفحة «تكلفة Claude» أسفل الرئيسية: تكلفة كل درس وكل حلقة (جدول `api_usage`).
- حماية من الهدر: الحلقة تنكتب مرتين بالكثير في اليوم، وما تنكتب مرتين بنفس الوقت، والدرس ما ينطلب مرتين لو حدّثت الصفحة.

## مهم
حط حد للصرف في console.anthropic.com ← Billing ← Spend limits.

## حلقة المشي اليومية 🎧
كل يوم الفجر يشتغل ملف العمل `.github/workflows/podcast.yml` في GitHub Actions: يطلب من التطبيق نص حلقة اليوم (يكتبه Claude من آخر درس وغلطاتك)، ويسجّله بصوتين عبر Piper، ويرفع MP3 للتطبيق، فتنزل حلقة جديدة في بودكاست خاص.

- ما فيه أي كلمة سر في GitHub: التطبيق يتحقق من هوية ملف العمل بتوقيع GitHub (OIDC).
- تقدر تشغّله يدوياً: GitHub ← Actions ← podcast ← Run workflow.

- محتوى الحلقة (حوالي ٣٠ دقيقة): مراجعة كلمات الأيام السابقة (١، ٣، ٧، ١٤، ٣٠ يوم)، ١٠ كلمات جديدة، شرح قواعد مع ترديد، ١٢ سؤال قواعد بنمط الستيب، ٤ مقاطع استماع مع أسئلة، محاضرة قصيرة مع ترديد، ومراجعة ختامية.
- رابط الاشتراك تلقاه في التطبيق: «حلقة المشي اليومية» ← انسخ رابط البودكاست.
- التخزين: KV باسم `step-podcast` (الصوت ينحذف تلقائياً بعد ٢٥ يوم، النص يبقى في D1).
- التكلفة: GitHub Actions مجاني للمستودعات العامة، ونص الحلقة طلبين من Claude يومياً.
- إيقاف الحلقة: من أسفل صفحة الحلقة.
